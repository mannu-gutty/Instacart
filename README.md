# Instacart
Customer Behavior Analysis

##  Project Description
This project analyzes Instacart customer purchase data to understand shopping habits, 
reordering behavior, and product demand patterns.

##  Tools Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

##  Key Analysis
- Purchase frequency and reorder behavior
- Most popular products and departments
- Time-based purchasing patterns
- Customer shopping habits analysis

##  Conclusion
The analysis provides insights into customer purchasing behavior and identifies trends 
that can help optimize product assortment and improve customer experience.
